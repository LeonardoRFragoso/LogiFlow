# 🎥 Planejamento de Vídeos de Treinamento - LogiFlow CRM

## 📋 Visão Geral

**Objetivo**: Criar série de vídeos tutoriais para onboarding e treinamento de novos usuários do LogiFlow CRM.

**Plataforma**: YouTube (canal privado) + Loom para vídeos rápidos

**Total de Vídeos**: 8 vídeos principais + 5 complementares

**Duração Total**: ~60 minutos

---

### Gravação
- **OBS Studio** (grátis) - Captura de tela
- **Loom** (grátis até 5min) - Vídeos rápidos
- **Microfone**: Blue Yeti ou similar
- **Webcam**: Logitech C920 ou similar

### Edição
- **DaVinci Resolve** (grátis) - Edição profissional
- **Canva** (grátis) - Thumbnails

- **YouTube** (canal privado)

## 💡 Dicas de Produção

### Roteiro
- Seja objetivo e direto
- Use linguagem simples
- Mostre, não apenas explique
- Repita pontos importantes

### Gravação
- Ambiente silencioso
- Boa iluminação
- Fale claramente
- Pause entre seções

### Edição
- Corte silêncios longos
- Adicione zoom em detalhes
- Use setas e destaques
- Mantenha ritmo dinâmico

### Acessibilidade
- Adicione legendas (PT-BR)
- Transcrição completa
- Descrição detalhada
- Timestamps nos comentários
