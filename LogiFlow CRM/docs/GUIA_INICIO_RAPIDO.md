# LogiFlow CRM - Guia de Início Rápido

Bem-vindo ao LogiFlow CRM! Este guia vai te ajudar a começar em poucos minutos.

## 🚀 Primeiros Passos (5 minutos)

### 1. Acesse o Sistema
- URL: Fornecida pela equipe LogiFlow
- Usuário: Seu e-mail cadastrado
- Senha: Enviada por e-mail

### 2. Complete seu Perfil
1. Clique no seu nome (canto superior direito)
2. Selecione "Meu Perfil"
3. Adicione foto e informações de contato
4. Salve as alterações

### 3. Conheça o Dashboard
O dashboard principal mostra:
- 📊 **Entregas do dia** - Quantas entregas estão programadas
- 🚚 **Em trânsito** - Entregas em andamento
- ⚠️ **Alertas** - Problemas que precisam de atenção
- 💰 **Faturamento do mês** - Receita atual

## 📋 Tarefas Essenciais

### Cadastrar um Cliente

1. Menu lateral → **Clientes** → **Novo Cliente**
2. Preencha os dados obrigatórios:
   - Nome da empresa
   - CNPJ
   - E-mail
   - Telefone
3. Adicione endereço completo
4. Defina condição de pagamento
5. Clique em **Salvar**

**Dica:** Use o botão "Buscar CNPJ" para preencher automaticamente os dados da Receita Federal.

### Criar uma Cotação

1. Menu → **Comercial** → **Nova Cotação**
2. Selecione o cliente
3. Preencha origem e destino
4. Informe tipo de carga e peso
5. Sistema calcula valor automaticamente
6. Ajuste o valor se necessário
7. Defina prazo de entrega
8. Clique em **Enviar Cotação**

**O cliente receberá a cotação por e-mail automaticamente!**

### Aprovar Cotação e Criar Pedido

1. Abra a cotação aprovada pelo cliente
2. Clique em **Aprovar Cotação**
3. Sistema cria o pedido automaticamente
4. Atribua motorista e veículo
5. Confirme os dados
6. Pedido está pronto para coleta!

### Registrar uma Entrega

1. Menu → **Operacional** → **Entregas**
2. Localize o pedido
3. Clique em **Atualizar Status**
4. Selecione o novo status:
   - Coletado
   - Em trânsito
   - Em entrega
   - Entregue
5. Adicione observações se necessário
6. Salve

**Dica:** O motorista pode fazer isso pelo app!

## 🎯 Fluxo Completo de Trabalho

```
1. COTAÇÃO
   ↓ Cliente aprova
2. PEDIDO
   ↓ Atribuir motorista/veículo
3. COLETA
   ↓ Motorista coleta a carga
4. EM TRÂNSITO
   ↓ Rastreamento ativo
5. ENTREGA
   ↓ Comprovante com foto
6. CONCLUÍDO
   ↓ Faturamento
7. FINANCEIRO
```

## 🔔 Notificações

Você receberá notificações por:

- 📱 **WhatsApp** - Alertas urgentes (opcional)

3. Defina horários de envio
4. Salve

## 📊 Relatórios Rápidos

### Entregas do Dia
Menu → **Relatórios** → **Entregas do Dia**

### Performance de Motoristas
Menu → **Relatórios** → **Motoristas** → **Performance**

### Faturamento Mensal
Menu → **Financeiro** → **Faturamento**

## ⚙️ Configurações Importantes

### Adicionar Usuários

1. Menu → **Configurações** → **Usuários**
2. Clique em **Novo Usuário**
3. Preencha dados e defina permissões
4. Usuário recebe e-mail com instruções

### Definir Tabela de Preços

1. Menu → **Configurações** → **Tabela de Preços**
2. Configure por:
   - Distância (km)
   - Peso (kg)
   - Tipo de carga
   - Região
3. Sistema usa para cotações automáticas
